# Bundled fonts

Cormorant Garamond (500/600 and 500 italic), IBM Plex Sans (400/500/600) and IBM Plex Mono (400/500) are bundled from Google Fonts. Each family is distributed under its included SIL Open Font License. Fonts are unmodified WOFF2 files; manifest.json records original URLs and SHA-256 checksums.

fonts.css retains the original Unicode subsets. Japanese and Chinese use the existing installed-font fallback stacks (Noto if installed, then native fonts). No font service is contacted by PMCO at runtime.
